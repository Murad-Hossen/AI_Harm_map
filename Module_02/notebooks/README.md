# Canonical notebooks

These two notebooks correspond to the current working implementation supplied
for the paper repository.

- `01_full_model_training_evaluation.ipynb` — full extraction/evaluation,
  Pairwise temporal KG baseline, PHTKG training, tuning, diagnostics, checkpoint
  export, learned representations, recurrence, and pattern analysis.
- `02_incremental_inference.ipynb` — append-only extraction of unseen reports,
  supplied-class fit verification, fixed-checkpoint PHTKG inference, recurrence,
  similarity, incremental entity-state evolution, clustering, and final enriched
  output.

The GitHub copies have execution outputs and identifying development metadata
removed. Exact unmodified originals are retained in the master working bundle
under `local_artifacts/notebooks_exact/` and are excluded from Git.
