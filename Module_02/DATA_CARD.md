# Data card

The project represents curated reports as structured AI-harm events. Each
event may contain an AI system, organization, affected group, action, harm
category, consequence, location, event date, source, evidence, confidence,
and audit metadata.

The authoritative taxonomy is stored in
`data/taxonomy/AI_Harm_Map_Taxonomy_Schema_vSHARED.xlsx`.

Full article text should not be assumed redistributable. For that reason,
source/full-evidence working artifacts live in `local_artifacts/`, which is
excluded from Git. A public derived-data release should be frozen only after
redistribution and licensing review.
